# Company-Performance-Analysis

## 🎯 Objective  
Analyze **company performance** using key metrics for sales, profit, and customers — highlighting:  
- Top-performing employees  
- Major clients and their contribution  
- Regional profitability  
- Sales trends and best-selling products  

The goal is to identify strengths, risks, and opportunities to guide better strategic decisions.

## 📊 Overview  
This project provides a detailed view of how the company performs across people, products, and regions.  
It uses Excel tools to uncover which employees, clients, and areas drive the most value — and where attention is needed to sustain growth.

### 1. 🧹 Data Cleaning  
- Standardized regions, employee names, and product categories  
- Removed missing and duplicate entries  
- Used **Power Query** for transformation and loading  

### 2. 🧩 Data Modeling  
- Built relationships using **Power Pivot**  
- Created **DAX calculations** for profit, tax, and KPIs  

### 3. 📈 Visualization  
- Developed interactive **PivotTables** and **Charts**  
- Added **Slicers** for filtering by year, region, and employee  
- Designed a dashboard summarizing company performance

 ## 🧠 Tools & Features  
| Tool | Purpose |
|------|----------|
| **Excel Power Query** | Data cleaning & transformation |
| **Power Pivot** | Data modeling & DAX measures |
| **PivotTables & Charts** | Data exploration & analysis |
| **Slicers & KPIs** | Dashboard interactivity |
